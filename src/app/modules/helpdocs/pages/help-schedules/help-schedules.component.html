Schedules

This section provides information about managing schedules within the application. You can create, edit, and delete schedules as needed, either as an automated process or a manual task.



View Types

You can view schedules in two different formats:

  • Calendar View: — Displays schedules in a calendar format, allowing you to see events and shifts organized by days and weeks.
  • List View: — Presents schedules in a tabular format, making it easy to see details of each schedule entry in a list.

General Schedule Actions

Several general actions can be performed on schedules:

  • View Toggle — Switch between Calendar and List views to suit your preference.
  • Start Date / End Date — Select the date range for which you want to view or manage schedules.
  • Export — Export the current schedule view to an Excel file for offline access or reporting purposes.
  • Search — Filter schedules based on specific date range.
  • Create Schedule — Initiate the process of creating a new schedule. This option is typically available to users with the necessary permissions.
  • Delete Schedule — Remove an existing schedule from the system. This action is irreversible and should be performed with caution.


Specific Schedule Actions

In "List View", pressing a table cell where the worker and a specific date meet, will show a menu of actions that can be performed specific to a worker or schedule. Here's a list of what it can do:

  • View Day Schedule — Shows the list of shift entries that a worker is a assigned to, in that specific day.
  • Manage Day Schedule — Opens a window that a manager can use to create schedule entries for its shifts, who participates in them and their roles.
  • Assign Shift — Quick action to assign a worker to a specific shift on the selected day.
  • Start Rotation Cycle — Saves the start date of a rotation cycle request, for a specific worker. NOTE: Only available for workers who are part of the rotation.
  • Cancel Rotation — Cancels any active rotation cycle that was being configured for a specific worker. NOTE: Only available for workers who are part of the rotation.
  • End Rotation Cycle — Sets a rotation cycle from the previously stored start date to the date specified, for a specific worker. NOTE: Only available for workers who are part of the rotation.
  • Clear Daily Assignments — Removes all daily assignments a worker has on a specific day.
  • Clear All Employee Assignments — Removes all assignments within the current range period to that specific worker.

These actions are covered more in depth, in the "Manual Scheduling" section of this page.



Managing Schedule

Schedules can be managed with the existing automated process or through the various manual processes that the application has to offer.


Automated Scheduling

The automated scheduling feature allows users to set up schedules that are generated based on predefined rules and criteria. This can help streamline the scheduling process and ensure consistency across different time periods.

For this operation to work, members, shifts and rule configurations already have to be in place. Once that is done, access the Schedules page of your work entity and press "Create Schedule" button.

This will open the Create Schedule Window where it will presented with the following options:

  • Start Date — Sets the start date to where the scheduling process will begin.
  • End Date — Sets the end date to where the scheduling process will end.
  • Single Role Responsibility — Determines if a worker will be assigned to a single skill responsibility when assigned to a shift entry.
  • Clear Existing Schedule — When checked, it will create the schedule from scratch, removing any existing previous entries, before creating the new schedule.
  • Filterable — Shows the list of members, shifts and rules that the user can select to filter its application on the schedule generation.

When pressing the filterable button, tabbed pages for members, shifts and rules will appear. For each one, you will have a checkbox that you can click to specify what you want to use for your schedule generation.

Once everything is set, press the "Create" button that is presented at the bottom of the page.

This will trigger a warning window to confirm all of the selections, requiring therefore a confirmation.

After confirming, the system will process the request and generate the schedule based on the provided criteria. Depending on the size of the dataset and complexity of the rules, this may take some time.



Manual Scheduling

Manual scheduling provides users with the flexibility to create and adjust schedules as needed. This is particularly useful for handling unique situations or last-minute changes that may not be accommodated by automated processes.

Viewing Day Schedule

You can view daily schedules in both view modes. In Calendar mode, you select the colored dots that exist. In List mode, clicking on a specific cell of the table will show a menu of options where you can select the "View Day Schedule". The following view will appear:

This view will show the shift entries that a specific worker is assigned to. If there is a more than one entry, an option will appear to switch events. Here it specifies:

  • Event Name — The name of the event which will always be the shift name.
  • Start/End — The start and end date and time of the shift.
  • Participants — A list of all participants in this entry and skills assigned to them.


Manage Day Schedule

Manage Day Schedule is an option that the manager can use when he wants to be more hands on. When clicked, the following window will appear:

The manager can create schedule entries for its shifts, who participates in them and their roles. To start, if there are no entries, we select a shift and press the "Add Entry" button. Otherwise, you can select existing entries.

Once an entry is created/selected, a list of available members will appear on left column. You can select one or more workers and then use one of 4 buttons that exist in the middle column, efectively assigning members to the schedule entry.


first_page Removes all participating workers
chevron_left Removes selected workers from the entry
chevron_right Assigns selected workers to the entry
last_page Assigns all available workers to the entry

For each assigned worker, you can also specify the skill that he will be using for this entry. By default, all workers skills will already be present, but there will be cancel icon that allows for the removal of that skill. This is subject to change if required, for a add icon with "Add Skill".

Once that happens, a window will appear to select any skill that isnt currently active. Pressing "Add Skill" button will add the skill again to the worker.

Once everything is set, press the "Save" button at the bottom right of the page to save all changes made.



Assign Shift

One quick way to add worker to a specific shift, navigate to the desired date and worker in the schedule view. Click on the corresponding cell to open the action menu, then select "Assign Shift". A submenu will appear with a list of available shifts. Click on the desired shift to assign it to the worker for that day.



Start Rotation Cycle

One of the tools created for workers who are part of the work entity rotation, is to create a rotation cycle. The intent is for the worker to set the rotation from a range period. When pressing "Start Rotation Cycle" option, it will store the worker and the start date of the rotation cycle, allowing the user to select when the rotation cycle ends.



Cancel Rotation

Pressing "Cancel Rotation" will clear the previously saved start date and worker references



End Rotation Cycle

When pressing "End Rotation Cycle" in a specific end date, the application will take both dates and worker references to assign the worker in a rotation cycle from that interval range.



Clear Daily Assignments

This option will clear all assignments that a worker has on the selected date.



Clear All Employee Assignments

This will remove all employee assignments from the current range dates that is current selected.
